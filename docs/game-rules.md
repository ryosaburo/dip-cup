# ゲームルール

「AIエージェント学習対戦」は、「現実」か「妄想」かを読み合うターン制の1対1対戦ゲーム。サポートカード等は廃止されており、現実／妄想の読み合いのみのシンプルな仕組みになっている。

## 基本の流れ

1ターンは「攻撃側が手を出す → 防御側が見破りに挑む → 判定」の3ステップで進み、ターンが終わるごとに攻守が交代する（先攻はルーム作成者＝ホスト）。

1. **攻撃側**が、現実カード12種類の中からそのターン用にランダムで配られた3種類のいずれか1枚、または妄想カードを選ぶ。配られる3種類は攻守交代のたびに毎回引き直される。妄想カードを選んだ場合はその場で「申告ダメージ量」（10〜60の範囲で自由に設定）も入力する。現実カードのうち「吸血」を選んだ場合も、その場で申告ダメージ量（1〜50の範囲）を入力する。
2. **防御側**は、攻撃側が確定させた「申告ダメージ量の数字」だけを確認できる（カードの種類は伏せられている）。その数字だけを手がかりに、これが「現実」か「妄想」かを予想する。
3. 予想が終わると判定が行われ、結果（見破ったか／見破られたか、ダメージ量、双方の残りライフ・妄想ゲージ）が両者に通知される。
4. 「次のターンへ」を押すと攻守が交代し、2に戻る。

同時に手を出す対戦ではなく、上記のとおり交互に手番が回ってくる点が特徴。

## 見破り判定のルール

- **防御側が種類を当てた（見破った）場合**：カードの効果は攻撃側にそのまま返らない。
  - **ダメージ系カード**：**攻撃側自身に跳ね返る**（自傷ダメージ）。
  - **回復系カード**（休息・無理な回復・緩やかな回復・回復申告の妄想）：**見破った防御側自身がそのライフを回復する**。攻撃側は回復できない。
  - **瞑想**（ゲージ系、例外）：効果が反転し、攻撃側の妄想ゲージが逆に上がる。
  - 見破られたのが**妄想カード**だった場合：上記の反動ダメージ／防御側回復に加えて、攻撃側の妄想ゲージが申告量と同じ%だけ上昇する。加えて、見破られる直前の妄想ゲージ%を確率とした抽選が行われ、外れると妄想ゲージが即座に100%になる（＝即敗北）。
- **防御側が外した（見破れなかった）場合**：申告どおりの効果が発生する。
  - **ダメージ系カード**：申告・計算どおりのダメージが防御側に通る。
  - **回復系カード**：攻撃側自身がそのライフを回復する。
  - **妄想カード**が成功した場合：ダメージ申告なら申告量がそのまま防御側に通り、回復申告なら攻撃側自身が申告量だけ回復する。このとき攻撃側・防御側どちらの妄想ゲージも変動しない。
  - **現実カード**は種類ごとに固有の効果を発揮する（詳細は次章）。

## 現実カード一覧（全12種、うち毎ターン3種がランダムに配られる）

| カード名 | 見破られなかった場合（成功） | 見破られた場合（失敗） |
|---|---|---|
| 着実な一撃 | 相手に20ダメージ。自分の妄想ゲージが15%下がる | 自分に20の反動ダメージ（ゲージ変動なし） |
| 圧殺の一撃 | 相手に25ダメージ（自分の妄想ゲージが60%以上なら2倍の50ダメージ） | 自分に同量の反動ダメージ |
| 疼く傷跡 | 相手に10ダメージ＋以後3ターン、ターン終了時ごとに10ダメージが入り続ける継続ダメージ | 自分に10の反動ダメージ＋継続ダメージも自分自身が受ける |
| 妄想の解放 | 自分の現在の妄想ゲージの値（%）がそのまま相手へのダメージになる | 自分に同量の反動ダメージ |
| 痛烈な一撃 | 相手に30ダメージ | 自分に30の反動ダメージ |
| 素早い一撃 | 相手に20ダメージ | 自分に20の反動ダメージ |
| 小さな一撃 | 相手に10ダメージ | 自分に10の反動ダメージ |
| 休息 | 自分のライフが30回復 | 自分は回復できず、見破った相手のライフが30回復する |
| 瞑想 | 自分の妄想ゲージが30%下がる（ダメージなし） | 妄想ゲージが逆に30%上がる（反転） |
| 無理な回復 | 自分のライフが50回復。**妄想ゲージも常に+20%**（デバフ前提の効果） | 自分は回復できず、見破った相手のライフが50回復する。**妄想ゲージ+20%は成功時と変わらず発生** |
| 緩やかな回復 | 以後3ターン、ターン終了時ごとに自分のライフが10回復し続ける。このターン自体には即時効果なし | 自分は回復できず、以後3ターン見破った相手のライフが10ずつ回復し続ける。このターンの即時効果はなし |
| 吸血 | 攻撃側が1〜50の範囲で申告したダメージを相手に与え、同じ量だけ自分も回復する | 自分は回復できず、申告した量の反動ダメージのみが自分に入る（ゲージ変動なし） |

補足:
- 「疼く傷跡」と「緩やかな回復」の継続効果は、攻守交代を挟んでも減衰せず、指定ターン数のあいだ毎ターン終了時に発動し続ける。
- 上記で妄想ゲージ変動が明記されていないカードは、妄想ゲージを変動させない。
- ライフの回復は開始時のライフ（100）が上限としてクランプされる（それ以上は回復しない）。

## 妄想カード

- 攻撃側は「ダメージ」「回復」のどちらの効果にするかを選び、10〜60の範囲で好きな「申告量」を設定して繰り出す。
- 防御側にはこの申告量の数字だけが見え、カードの種類（現実／妄想）も、ダメージ／回復のどちらかも伏せられる。
- **成功（見破られなかった）**：
  - ダメージ申告：申告した量がそのまま相手に通る。
  - 回復申告：申告した量だけ攻撃側自身が回復する。
  - いずれの場合も妄想ゲージはどちらも変動しない。
- **失敗（見破られた）**：
  - ダメージ申告：申告量分の反動ダメージが攻撃側自身に入る。
  - 回復申告：攻撃側は回復できず、見破った防御側が申告量だけ回復する。
  - いずれの場合も、申告量と同じ%だけ攻撃側の妄想ゲージが上昇する。加えて、見破られる直前の妄想ゲージ%を確率とした抽選が行われ、外れると妄想ゲージが即座に100%になり即敗北となる。
- 妄想カードで相手の妄想ゲージを直接変動させることはできない（見破られた際に攻撃側自身のゲージが上がるのみ）。

## 勝敗条件

- 開始時のライフは両者とも100固定。
- 次のいずれかを満たしたプレイヤーは敗北する。
  - ライフが0以下になる
  - 妄想ゲージが100%に達する（見破られた妄想カードの即敗北抽選を含む）
- 両者が同一ターンで同時に敗北条件を満たした場合は引き分けとなる。

## 対戦の作成・参加

- プレイヤー名を入力し、「ルーム作成」でルームコードを発行するか、他プレイヤーから受け取ったコードで「入室する」ことで対戦が始まる。
- ログインは任意（Supabase認証によるメール・パスワードログイン）。ログインしなくてもゲストとして対戦でき、ログインした場合はプロフィールと対戦履歴が保存される。
- 先攻（最初の攻撃側）は常にルーム作成者（ホスト）。
